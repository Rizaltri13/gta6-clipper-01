An 11-second vertical YouTube Short cut by an AI agent from Rockstar's
official Grand Theft Auto VI Trailer 2: the moment Lucia Caminos walks
out of Leonida Penitentiary a free woman, with Jason waiting for her.
The clip closes with the make.fun pitch — make clips like this with AI
and earn money on make.fun. Watch it at
https://www.youtube.com/shorts/XEgGOqD4OBM

`main.ts` copies `VIDEO.json` to the output directory, the way the
make.fun grader runs it:

```
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
